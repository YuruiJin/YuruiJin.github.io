## Overview

This project developed a BERT-based sentiment analysis model for movie reviews, with emphasis on robust learning under class imbalance and interpretable predictions.

## Method

- Trained a BERT model for review-level sentiment classification.
- Addressed data imbalance with augmentation, resampling, and weighted loss.
- Used LIME and SHAP to visualize token-level contributions and improve interpretability.
